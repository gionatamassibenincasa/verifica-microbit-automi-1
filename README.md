## 📌 1. Regola di Assegnazione della Traccia

Per evitare sovrapposizioni e garantire un lavoro individuale, **la traccia da svolgere è assegnata in modo vincolante** in base al tuo numero di registro di classe (calcolo del resto con la formula `Numero % 3`):

* 🔴 **TRACCIA A** (`TRACCIA_A.md`): se **$\text{Numero di Registro} \pmod 3 = 1$**  
  *(Es. Studenti n. 1, 4, 7, 10, 13, 16, 19, ...)*
* 🟡 **TRACCIA B** (`TRACCIA_B.md`): se **$\text{Numero di Registro} \pmod 3 = 2$**  
  *(Es. Studenti n. 2, 5, 8, 11, 14, 17, 20, ...)*
* 🟢 **TRACCIA C** (`TRACCIA_C.md`): se **$\text{Numero di Registro} \pmod 3 = 0$**  
  *(Es. Studenti n. 3, 6, 9, 12, 15, 18, 21, ...)*

> **Attenzione:** Svolgere una traccia diversa da quella associata al proprio numero di registro comporterà l'invalidazione della prova. Apri il file `.md` corrispondente presente in questo repository per leggere il testo dei tuoi esercizi.

## 🛠️ 2. Modalità di Sviluppo del Codice

1. Accedi a [makecode.microbit.org](https://makecode.microbit.org/) ed effettua il login cliccando sull'icona **GitHub** (in alto a destra) con le credenziali del tuo account collegato a Classroom50.
2. Per **ciascuno dei 5 esercizi** previsti dalla tua traccia, crea un **nuovo progetto** MakeCode distinto.
3. Denomina i 5 progetti in modo preciso e trasparente:
   * `Esercizio_1`
   * `Esercizio_2`
   * `Esercizio_3`
   * `Esercizio_4`
   * `Esercizio_5`
4. Programma ciascun esercizio utilizzando unicamente l'interfaccia **a blocchi**.

---

## 📦 3. Procedura di Consegna dei File `.hex`

Poiché la verifica richiede la consegna di 5 progetti separati, la consegna avviene caricando i file `.hex` scaricati da MakeCode all'interno di questo repository.

### Passo 1: Download dei file `.hex` da MakeCode
Al termine di ciascun esercizio, clicca sul pulsante **Salva** (icona del disco in basso a sinistra) nell'editor di MakeCode. Verrà scaricato sul tuo computer un file `.hex` (es. `microbit-Esercizio_1.hex`).

### Passo 2: Upload su GitHub
1. Apri la pagina principale di **questo repository GitHub** generato da Classroom50.
2. Clicca in alto a destra su **Add file** $\rightarrow$ **Upload files**.
